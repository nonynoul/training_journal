Программа для учёта тренировок

Модули:
    Модуль exercise.py: класс Exercise (название, тип, длительность).
    Модуль workout.py: класс Workout (дата, набор упражнений).
    Модуль log.py: класс WorkoutLog, обобщение данных и статистика.

Функционал:
    Добавить упражнение,
    Создать тренировку,
    Подсчитать общую длительность,
    Сохранить тренировку,
    Вывести статистику.
